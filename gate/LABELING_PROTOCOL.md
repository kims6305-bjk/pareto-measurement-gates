# Phase 1 Human Labeling Protocol (declared before labeling)

선언 시점: 라벨링 시작 **전** 커밋 — 결과를 보고 정의를 고르는 순환을 차단하기 위해 기준을 먼저 고정한다.

## 대상

`gate/scripts/phase1_human_label_sheet.xlsx` — 55 claims
= 저지가 CONTRADICTED/INSUFFICIENT로 판정한 23건 전수 + VERIFIED 표본 32건, 셔플·블라인드(저지 라벨/사유 열 숨김).

라벨러: 저자 (도메인 전문가, 저지 출력 비공개 상태에서 라벨).

## 라벨 척도

게이트의 시맨틱 라벨(SUPPORTED / CONTRADICTED / INSUFFICIENT)과 동일 척도:

| 라벨 | 기준 |
|---|---|
| **S** | claim이 제공된 근거 문단에 명시돼 있거나 직접 도출됨 |
| **C** | 근거 문단이 claim과 반대되는 내용을 진술 |
| **I** | 근거만으로 확인 불가 — **회계적으로 옳은 주장이라도 제공된 근거 범위 밖이면 I** |

판단 기준은 "근거가 claim을 지지하는가"뿐이다. 라벨러의 도메인 지식으로 참/거짓을 판정하지 않는다 (citation attribution 표준 관행).

## 규칙

1. **맥락 채점**: claim은 전체 답변 맥락에서 읽는다. 접속문 분해 아티팩트(하나의 완전한 문장이 c1/c2로 쪼개진 경우)는 전체 답변+근거에서 성립하면 S로 라벨하되, 메모란에 `분해`를 기록한다.
2. **명제 없음**: claim 텍스트가 명제가 아니면(예: "제공된 자료에서 확인되지 않음") I + 메모 `명제없음`. 채점 시 별도 분리.
3. **애매**: S/I 경계에서 애매하면 I로 기울이고 메모 한 줄.
4. **블라인드**: 숨김 열(저지 라벨·사유)은 라벨 완료 전 열람 금지.

## 채점 (라벨 완료 후)

- 사람 라벨 = ground truth로 저지 P/R 계산. 사전 목표: **P·R ≥ 90%** (라벨 전 선언).
- `분해` 표시 건은 두 정의로 이중 계산해 병기한다:
  - **맥락 기준**: 분해 건의 정답 = S (본 프로토콜의 1차 정의)
  - **고립 기준**: 분해 건을 claim 단독으로 재라벨한 값
  - 어느 정의에서든 결론(저지 합격/불합격)이 유지되는지 보고 — 정의 선택에 따른 결과 뒤집힘을 명시적으로 검사.
- `명제없음` 건은 P/R 모집단에서 제외하고 추출 불량률로 따로 보고.
- 목표 미달 시: 개선판 저지(전체 답변 + 형제 claim 동봉) before/after 실측 → prereg v2.

## 한계 (정직 고지)

- 라벨러 1인 — inter-rater 신뢰도 미측정. 라벨러는 프로젝트 이해당사자이나, 저지 출력 블라인드로 방향 편향을 차단.
- 55건은 저지 양성(시비) 전수 + 음성 표본이므로 P/R 추정의 분산이 큼. 이 측정은 저지 채택/기각 게이트이지 정밀 벤치마크가 아니다.
