# 계기 검침 사전 선언 (Instrument Check) — 실행 전 커밋

**이 문서를 커밋한 뒤에 검침을 실행한다.** 결과를 보고 기준을 바꾸지 않는다.

## 0. 왜 이것이 필요한가

Phase 3는 1,650콜을 태우고 검정 불가로 끝났다. 원인은 조건 A(대조)의 문제 판정이
**0건**이어서 뒤집힐 대상이 없었던 것이다(`PHASE3_VERDICT.md` §2).

Phase 1·2·3의 실패는 **매번 다른 층에서 같은 실수**였다:

| Phase | 안 잰 것 | 결과 |
|---|---|---|
| 1 | 프로브 판정의 재현성 | 3회 실측에서 흔들림 발견(사후) |
| 2 | 사람 라벨 기저율 | 파일럿에서 3.3% 확인 → 목표 미달 |
| 3 | **저지 판정 기저율** | 0% → 검정 불가 |

세 번 다 "표본 크기는 셌지만 **측정 도구가 신호를 잡는지**는 안 쟀다".
따라서 이후 모든 실험은 본 실행 전에 **계기 검침**을 통과해야 한다.

## 1. 가르려는 두 가설

Phase 3에서 문제 판정이 0건이었던 이유는 둘 중 하나다. 지금은 구별되지 않는다.

> **가설 I (계기 고장)**: Phase 3의 저지 프롬프트가 문제를 검출하지 못하는 구성이다.
> 코퍼스에 문제가 있어도 SUPPORTED를 낸다.
>
> **가설 C (코퍼스 공백)**: Phase 3 저지는 정상이고, 확증 집합에 실제로 문제가 없었다.
> 확증 집합은 "이전에 흥미로웠던 문항 56개를 제외한 나머지"이므로 그럴 수 있다.

두 가설의 처방이 정반대다. I면 **저지를 고쳐야** 하고, C면 **표본을 바꿔야** 한다.
가르지 않고 진행하면 틀린 쪽을 고치게 된다.

## 2. 코드 실측으로 확인된 차이 (프롬프트 대조)

`phase1_judge_v3.py`(사람 라벨로 P/R 검증됨) vs `phase3_build_prompts.py`:

| 요소 | v3 (Phase 1) | Phase 3 저지 |
|---|---|---|
| `[전체 답변]` 블록 | **있음** | **없음** |
| "규칙의 왜곡 → CONTRADICTED" 지침 | **있음**(지침 2) | **없음** |
| 형제 주장 블록 | 항상 있음 | 조건 B에만 |
| 라벨 계약 | 4라벨 | 3라벨 |

v3의 CONTRADICTED는 대부분 "필요조건을 충분조건처럼 단정" 축에서 나온다.
Phase 3 프롬프트에는 그 축을 판정하라는 지시가 **존재하지 않는다.**
이것이 가설 I의 근거지만, **근거는 가설이지 판정이 아니다.** 아래로 실측한다.

## 3. 설계 — 같은 저지를 라벨된 표본에 물린다

**Phase 3의 저지 프롬프트를 그대로**(한 글자도 고치지 않고) Phase 1 라벨 55건에
적용한다. 55건에는 사람이 문제로 판정한 것이 **11건**(CONTRADICTED 8, INSUFFICIENT 3)
있다는 것이 이미 확정돼 있다.

- 라벨 55건은 **정답지**이며 이 검침으로 재라벨·수정하지 않는다(결정 6).
- 조건은 형제 문맥 **포함**(Phase 3 조건 B)으로 고정한다. v3도 형제를 항상 주므로
  v3와 가장 가까운 구성이며, 계기의 최대 성능을 보는 것이 검침의 목적이다.
- 재현성 규율 유지: **3판 다수결**. 단일 실행 수치를 성능으로 보고하지 않는다.
- 비용: 55 × 3 = **165콜** ≈ 15분. Phase 3의 10분의 1이다.
  이것이 계기 검침을 게이트로 두는 실질적 이유다.

## 4. 🔴 사전 선언한 판정 기준 (결과 확인 후 변경 금지)

사람 라벨 문제 11건 중 저지가 문제(CONTRADICTED/INSUFFICIENT)로 판정한 수를
**검출 회수율(recall)**로 정의한다. 정밀도도 함께 보고하되 게이트에 쓰지 않는다
(Phase 3에서 확인된 실패 모드는 과검출이 아니라 **무검출**이다).

| 판정 | 조건 | 해석 | 처방 |
|---|---|---|---|
| **PASS** | recall ≥ 30% (≥4/11) **and** CONTRADICTED 1건 이상 | 계기 정상 → **가설 C 지지** | 저지 유지, 표본을 바꾼다 |
| **DEGRADED** | 0 < recall < 30% | 계기 둔감 | 저지 교정 후 재검침 |
| **FAIL** | recall = 0 | 계기 고장 → **가설 I 확정** | 저지 폐기, v3 계열로 재구성 |

**임계 30%의 근거**: Phase 1 v3의 실측 C-recall이 50~60%였다(`phase1_final_comparison.json`).
Phase 3 저지는 지침이 의도적으로 단순하므로 그보다 낮게 잡되, 0과는 명확히 구별되는
값으로 30%를 사전에 고정한다. 결과를 보고 조정하지 않는다.

**PASS가 나와도 Phase 3 결론은 바뀌지 않는다.** Phase 3는 여전히 검정 불가이며,
PASS는 "그 원인이 저지가 아니라 표본이었다"는 설명을 줄 뿐이다.

## 5. 이 검침이 답하지 못하는 것

- 55건은 Phase 1에서 **문제가 있을 법한 곳을 골라 뽑은 표본**이다(기저율 20%).
  따라서 여기서 나온 recall은 **일반 코퍼스에서의 recall이 아니다.**
  검침의 목적은 절대 성능 측정이 아니라 **"신호를 잡기는 하는가"**의 이진 판별이다.
- 55건은 v3 개발에 쓰인 dev 셋이다. v3에게 유리하고 Phase 3 저지에게 불리한
  비대칭이 있다. 그러나 검침 대상은 Phase 3 저지 **단독**이며 v3와 순위를 겨루는
  실험이 아니므로, 이 비대칭은 판정을 무효화하지 않는다. 다만 결론에 병기한다.
- 3판 다수결로도 갈리는 건(SPLIT)은 별도 집계하고 문제 판정으로 세지 않는다.
