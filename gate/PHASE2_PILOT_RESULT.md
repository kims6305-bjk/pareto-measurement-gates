# Phase 2 파일럿 결과 — 기저율 실측과 그 함의

`PHASE2_INTERNAL_PILOT.md` 를 커밋한 뒤 파일럿 30건을 라벨하고 §3 규칙을 그대로
적용한 결과다. 규칙은 실행 후 수정하지 않았다.

## 1. 실측

| 항목 | 값 |
|---|---|
| 라벨 총수 | 30건 (전량 라벨, 미라벨 0) |
| 명제없음 | 0건 → 분모 30 |
| 문제 사례(C 또는 I) | **1건** (Q088-c1, 라벨 I) |
| **기저율 p̂** | **0.033** (Wilson 95% CI [0.006, 0.167]) |
| 문제가 걸친 서로 다른 답변 | 1개 |

메모 태그: 분해 11건 / 선택분기 4건 / 명제없음 0건. 메모 기재율 20/30.

## 2. 사전 규칙이 산출한 N (재량 없음)

```
N_req = ceil(55 / 0.033) = 1650
N     = clamp(1650, 90, 201) = 201   ← 후보 풀 전량
```

`N_req(1650) > 후보 풀(201)` 이므로 §3에 선언한 대로 **"목표 55건 미달 — 판정 불가
가능"을 명기**한다. 이 문장은 결과를 보고 붙인 것이 아니라 파일럿 이전에 선언돼 있었다.

## 3. 핵심 함의 — 후보 풀을 다 태워도 목표에 못 미친다

`phase2_pilot_projection.py` 실측:

| 가정 | 201건 전량 라벨 시 기대 문제 사례 | 목표 55건 대비 |
|---|---|---|
| 점추정 p̂=0.033 | 6.7건 | 12% |
| CI 하한 p=0.006 | 1.2건 | 2% |
| CI 상한 p=0.167 (가장 낙관) | 33.5건 | 61% |

목표 55건을 채우려면 **점추정 기준 1,650건**(후보 풀의 8.2배), 가장 낙관적인 CI 상한을
써도 **330건**(1.6배)이 필요하다. 후보 풀에는 그만큼이 없다.

즉 **Phase 2를 원안대로 완주해도 회수율 90% vs 70%를 구간 비겹침으로 구별할 수 없다.**
남은 171건을 라벨하는 것은 검정력을 목표에 도달시키지 못하면서 비용만 쓰는,
파레토상 열등한 선택이다.

## 4. Phase 1 기저율 18.5%와의 차이 — 오류가 아니라 예측된 것

Phase 1 표본은 **"저지가 시비 건 건 전수 + VERIFIED 표본"** 이라는 편향 추출이었다.
문제가 있을 법한 건을 의도적으로 모았으니 기저율이 높게 나오는 것이 당연하다.
Phase 2 후보는 74문항에서 무작위 추출이므로 기저율이 낮게 나오는 것이 정상이다.

**이 차이가 바로 파일럿을 넣은 이유다.** Phase 1 기저율 18.5%를 그대로 대입해
N=300을 잡았다면 라벨 300건을 태우고 나서야 "문제 사례 10건, 판정 불가"를 알게 됐을
것이다. 파일럿 30건이 그것을 **171건 아끼고** 미리 잡았다.

## 5. 이 결과를 어떻게 쓰는가 (다음 결정은 bjkim)

파일럿은 N을 정하는 장치이지 실험 방향을 정하는 장치가 아니다. 방향 전환은 새로운
사전 선언을 요구한다. 아래는 선택지 정리이며, **어느 것도 이 문서로 자동 실행되지 않는다.**

| 안 | 내용 | 대가 |
|---|---|---|
| A. 원안 완주 | 201건 전량 라벨 | 라벨 171건 추가, 기대 문제 6.7건 → **판정 불가 확정적**. 권장하지 않음 |
| B. 여기서 종결 | Phase 2를 "기저율 실측으로 조기 종결"로 마감 | 회수율 비교는 영구 미해결. 대신 파일럿 자체가 결과가 됨 |
| C. 문항 증설 | 새 문항을 만들어 풀을 키움 | 별도 사전 선언 필요. 1,650건 규모는 현실적으로 불가 |
| D. 목표 재설정 | 55건 목표(회수율 90 vs 70 구별)를 포기하고 다른 질문으로 | **새 사전 선언 필수.** 아래 참조 |

### D안이 유력한 이유 (판단, 아직 실행 아님)

STATE.md §논문 관점에 이미 적혀 있듯 이 프로젝트의 실질 산출물은 "프로브 효과"가
아니라 **"per-claim 채점이 인용검증기 평가를 체계적으로 왜곡한다"** 쪽이다.
그 주장에 필요한 것은 문제 사례가 아니라 **분해 아티팩트**이고, 파일럿 30건에서
**분해 11건 / 선택분기 4건**이 이미 나왔다 — 기저율 3.3%와 달리 이쪽은 풍부하다.
목표를 바꾸면 지금 표본으로도 검정력이 선다.

다만 이것은 **결과를 보고 목표를 바꾸는 것**이므로, 그대로 하면 Phase 2 회수율 실험의
사전등록 무결성과 충돌한다. 정직한 처리는 다음과 같다:

1. Phase 2 회수율 실험은 **"기저율 미달로 판정 불가"로 종결하고 그대로 보고**한다.
   결과를 숨기거나 다른 지표로 갈아치우지 않는다.
2. 분해 아티팩트 연구는 **Phase 3로 분리**하고 새 사전 선언을 커밋한 뒤 시작한다.
   파일럿 30건은 그 가설을 **생성**한 표본이므로, 검정 표본과 분리하거나
   "탐색적(exploratory)"으로 명시한다.

## 6. 한계

- n=30 기저율의 CI가 넓다([0.006, 0.167]). 다만 **CI 상한을 써도 목표 미달**이므로
  결론(원안 완주는 열등)은 불확실성 전 구간에서 유지된다.
- 문제 사례가 1건이라 그 1건(Q088-c1)의 라벨 정확성에 기저율이 통째로 의존한다.
  프로토콜 §4.2 2차 라벨러 교차검증을 이 건에 우선 적용할 가치가 있다.
- 파일럿은 표본 크기 문제만 푼다. Phase 1에서 확인된 군집화는 여전히 미해결이다.
