## 1. 왜 지금 고정하는가 — 선행연구가 이미 한 것
GEPA (Agrawal et al., arXiv:2507.19457v2, ICLR 2026) 표 3(p.10)은 파레토 기반 후보(부모) 선택을
SelectBestCandidate(+6.05%)·BeamSearch(+5.11%)와 비교해 +12.44%를 보고했다(Qwen3 8B).
따라서 "파레토 전선에서 부모를 고르는 규칙의 효과를 아무도 따로 시험하지 않았다"는 주장은 **철회**한다.
GEPA 표 3이 하지 **않은** 것 — 이 부속서가 겨누는 틈:

| 틈 | GEPA 표 3 | 이 실험 |
|---|---|---|
| G-a 무작위 부모 대조군 | 없음 (그리디·빔 대비) | **C1 = 전선 균등 무작위 부모**, `PARENT_SEED = 20260731` (정본 §2 그대로) |
| G-b 측정 노이즈 반영 판정 | 단일 점수 비교, CI 없음 | ci_qid(문항 군집 부트스트랩, B=2000, seed 20260730) + CI 겹침 = 판별 불가(정본 §4) |
| G-c 판정기 사전 검침 | 없음 | IC-0·IC-1(부속서2) 통과 후에만 시작 |
| G-d 반복(seed) | 단일 실행으로 보임(부록 미전수 확인) | 주 검정은 조건당 1회 — **이 점은 GEPA와 같다**(§4 한계) |

## 2. 주 검정 (Primary) — 바꾸지 않음, 명시만
- **H13**: 같은 후보 예산(조건당 10후보 = 1,650콜) 아래에서 C2(정본 §6 S1/S2/S3 + filter_strip 부모 규칙)의
  최종 전선이 C1(전선 유지 + 무작위 부모)의 최종 전선을 집합 dominance(D-dom, ci_qid)로 지배한다.
- 판정은 정본 판정표 V1~V7을 **그대로** 쓴다. 이 부속서는 C13 해석만 다음처럼 고정한다:
  - C2 ≻ C1 (V1 또는 "C1 만 지배"의 V2) → C13 **지지**(이 표본·이 예산, n=1 실행)
  - C2 ~ C1 (커버만/동률, V3) → C13 **기각** — 무작위 부모로도 충분. 결과로 그대로 보고
  - C1 ≻ C2 (V4) → C13 **반대 방향** 보고
  - T3/T4 조기정지·판정 불가(V5) → C13 **판정 불가**. 예산 증액·축 추가 금지(정본 §14.2)
- 부 검정(Secondary): C2 vs C0(전선 없음) = 전선 유지 자체의 기여. 정본 그대로.

## 3. 예산·순서 (정본 §5 유지, 수치 명시)
- 순서 C2 → C0 → C1 그대로(재배열 금지). **C13 판정에는 C2와 C1 둘 다 완주가 필요**하므로
  컷라인은 정본대로 P4(C1 완주), 누적 **5,445콜**(IC 495 포함). 이보다 적게 쓰고 C13을 주장하지 않는다.
- 소요 실측 근거: sonnet-5 c000 run1 55콜 9분 32초(파일 생성 02:17:19 → 완료 02:26:51) → 조건당 1,650콜 ≈ 5시간(추정), C0+C1+C2 ≈ 15시간.
- 반복(G-d)은 주 검정에 넣지 않는다. 예산이 남으면 **P8: C1·C2 각 1회 추가 반복**(seed 20261006,
  제안기 동일)을 하고, 반복 간 결론 일치 여부만 보고한다. P8 결과로 주 검정 판정을 바꾸지 않는다.

## 4. 실행 전 구현 의무 (지금 없는 것 — 숨기지 않음)
정본 §2·§10 기준 아직 **미구현**이며, 각 항목은 첫 탐색 콜 **이전에** 별도 커밋으로 끝낸다:
- 후보 제안기(변이 생성) + `mh_propose.md` 수정 가능 표면 목록(U11) — 조건 간 동일, C2 실행 전 커밋
- C1 무작위 부모 추출기와 `PARENT_SEED` 상수(정본 §2 C1 행)
- C2 S3 슬롯 `mh_pair_diagnose.py`, filter_strip `mh_filter_candidates.py`
- 조건별 원장 분리(U4), C0 정지 규칙(U12), `REJECTED_C0` 상태(U3)
- 집합 dominance 자동 판정기(U9) — **판정표 V1~V7 선택을 사람 손으로 하지 않게**
- 미정 U5·U6 확정(첫 후보 측정 전)
각 구현은 자기검사(selftest) 통과 + 결정론 D-1~D-4 통과 전에는 콜을 쓰지 않는다.
