# Phase 2 종결 — 기저율 미달로 판정 불가 (네거티브 결과)

**결론: Phase 2가 답하려던 질문(회수율 90% vs 70%를 구별할 수 있는가)은 이 코퍼스에서
답할 수 없다. 표본 부족이며, 지표를 재정의하거나 사후 필터를 추가해 결론을 만들지 않는다.**

`PHASE2_LABELING_PROTOCOL.md` §5에 "이 목표에 미달하면 '표본 부족으로 판정 불가'라고
보고한다"고 사전 선언했고, 그대로 실행한 문서다.

## 1. 무엇을 하려 했나

Phase 1에서 프로브 효과가 판정 불가였던 원인은 문제 사례 10건·독립 답변 8개라는
표본 군집화였다. Phase 2는 라벨을 확장해 문제 사례 55건·독립 답변 25개를 확보하고
회수율 90%(per-claim)와 70%(answer-context)를 Wilson 구간 비겹침으로 구별하려 했다.

## 2. 어디서 멈췄나

필요 N이 기저율에 반비례하는데 그 기저율을 몰랐다. Phase 1 기저율 18.5%는 "저지가
시비 건 건 전수 + VERIFIED 표본"이라는 편향 추출이라 무작위 후보 풀에 적용할 수
없었다. 그래서 내부 파일럿(`PHASE2_INTERNAL_PILOT.md`)을 사전 선언하고 30건을 라벨해
기저율만 읽었다.

| 항목 | 값 |
|---|---|
| 파일럿 기저율 | **1/30 = 3.3%** (Wilson 95% CI [0.6%, 16.7%]) |
| 사전 규칙이 산출한 N | `clamp(ceil(55/0.033), 90, 201)` = **201** (후보 풀 전량) |
| 201건 전량 라벨 시 기대 문제 사례 | **6.7건** (CI 상한을 써도 33.5건) |
| 목표 55건 달성에 필요한 라벨 | 점추정 1,650건 / 낙관 330건 — 풀에 없음 |

**후보 풀을 전량 소진해도 목표에 도달하지 못한다.** 결론은 불확실성 전 구간에서
유지된다 — 가장 낙관적인 CI 상한을 써도 미달이다.

## 3. 판정

**Phase 2 = 판정 불가 (표본 부족).** 회수율 90% vs 70%의 우열은 이 프로젝트에서
미해결로 남는다.

남은 171건을 라벨하는 것은 검정력을 목표에 도달시키지 못하면서 라벨 비용만 쓰는
파레토 열등 선택이므로 **원안 완주를 하지 않는다.** 이것은 결과가 나쁘다고 중단한
것이 아니라, **효과 지표를 열지 않은 상태에서 표본 계산만으로 내린 결정**이다
(파일럿 열람 화이트리스트 §1.1 준수).

## 4. Phase 2가 실제로 생산한 것

실험은 실패했지만 세 가지가 남았다.

1. **Phase 1 기저율 18.5%가 편향 추출의 산물임을 실측으로 확인.** 무작위 추출에서는
   3.3%다. Phase 1의 모든 비율 수치를 해석할 때 이 사실이 필요하다.
2. **내부 파일럿 설계가 171건을 아꼈다.** 18.5%를 그대로 믿고 N=300을 잡았다면 300건을
   라벨한 뒤에야 판정 불가를 알았을 것이다. 30건으로 미리 잡았다.
3. **분해 아티팩트가 희소하지 않다는 관찰.** 파일럿 30건에서 분해 태그 11건.
   결과변수를 바꾸면 표본 문제가 해소될 수 있다는 단서이며, 이것이 Phase 3의 출발점이다.

## 5. 하지 않은 것 (무결성 고지)

- 목표 55건을 낮춰 "달성"으로 만들지 않았다.
- 회수율 대신 유리한 다른 지표로 갈아타 Phase 2를 성공으로 보고하지 않았다.
- 파일럿 단계에서 프로브·저지 출력을 열지 않았다. N 결정은 기저율만으로 이뤄졌다.
- 시드를 바꿔 파일럿을 다시 뽑지 않았다.

## 6. Phase 3와의 관계 (중요)

Phase 3(분해 아티팩트 연구)는 **Phase 2의 계속이 아니라 별개 실험**이다.
Phase 2 파일럿 30건은 Phase 3 가설을 **생성**한 표본이므로, Phase 3에서 그 30건을
검정 근거로 재사용하면 순환 논증이 된다. `PHASE3_PREREGISTRATION.md`에서 이를
어떻게 분리하는지 선언한다.

Phase 2의 결론(판정 불가)은 Phase 3의 결과와 무관하게 **그대로 보고된다.**

## 7. 재현

```bash
cd gate
.venv/bin/python scripts/phase2_power_analysis.py       # 필요 표본 55건 산출
.venv/bin/python scripts/phase2_determine_n.py          # 기저율 -> N (라벨 시트 필요)
.venv/bin/python scripts/phase2_pilot_projection.py     # 풀 소진 시 기대 문제 사례
.venv/bin/python scripts/phase2_verify_pilot_nesting.py # 중첩성·블라인드 검증
```

사전 선언 문서는 실행 **전** 커밋되어 있다(`18c4bd5` → 시트 생성 `4255ce3`).
