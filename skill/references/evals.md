# evals.md — Probe-Graph 이진 품질 게이트

두 층: ①프로브 자체 QA (도입 전) ②A/B 실측 게이트 (효과 판정).
모두 Y/N — 점수형 금지.

## ① 프로브 자체 QA (P3 → P2 → P1 순서로, 각 도입 전)

합성입력 스트레스테스트 — 정상답 5개 + 오류 심은 답 5개(조문 번호 오기,
수치 변조, 근거 밖 주장 삽입)를 만들어 프로브에 통과시킨다.

- [ ] 오류 심은 답 5개 중 심은 오류를 4개 이상 특정했는가? (위치+유형까지)
- [ ] 정상답 5개에서 억지 지적이 0건인가? (1건이라도 있으면 앵커 점검 — A1/A5 누락 의심)
- [ ] P1: quote 필드가 전부 근거 문서에 실존하는 원문인가? (프로브 자신의 환각 검사 — grep 대조)
- [ ] P1: needs_revision 판정이 items의 verdict와 논리적으로 일치하는가?
- [ ] P3: 출력이 답변 원문을 한 글자도 수정하지 않았는가?
- [ ] JSON 파싱이 10/10 성공하는가?

전 항목 Y → 다음 단계. 하나라도 N → 프롬프트 수정 후 재시험 (케이스 수정 금지).

## ② A/B 실측 게이트 (P1/P2 라이브 채택 판정)

### 사전 등록 (실험 시작 전 고정, 이후 수정 금지)

- [ ] 문항 80~100개 확정했는가? (N<80 금지 — 검정력: N=30→0.19, N=80→0.797, N=100→0.896)
- [ ] 문항이 전부 공개 기준서·법령 기반인가? (내부 데이터 0건)
- [ ] 문항 구성에 함정층 포함했는가? — 근거에 답 없는 문항 ≥15% (환각 유도),
      유사 조문 distractor 문항 ≥15% (CSQA형 위험 검사)
- [ ] 채점 기준(인용오류 정의)을 문서로 고정했는가?
- [ ] 합격/폐기 기준을 아래대로 선언했는가?

### 실행

- [ ] 같은 문항 세트로 프로브 유/무 두 arm을 같은 모델·같은 날 실행했는가?
- [ ] 채점자(사람 또는 별도 채점 스크립트)가 arm을 모르는 상태로 채점했는가? (블라인드)

### 판정 (기계적 — "좋아진 것 같다" 금지)

- [ ] **주지표**: 인용오류율이 McNemar 양측 α=0.05에서 유의하게 개선됐는가?
- [ ] **가드레일 1**: 답변정확도가 비열화인가? (하락 시 폐기)
- [ ] **가드레일 2**: 과교정율(정답→오답 전환)이 ≤0.5%인가? (EIR 임계 — 초과 시 폐기)
- [ ] 3항목 전부 Y → 채택, 사람 승인을 거쳐 라이브 반영
- [ ] 주지표 N이지만 가드레일 2종 Y → "무해·무효" 판정. P2는 보험으로 유지 가능,
      P1은 콜 비용 대비 무익이므로 폐기
- [ ] 가드레일 하나라도 N → 즉시 폐기. 문구 튜닝 재도전은 1회만 허용, 그것도 실패 시 종결

### P3 별도 평가 (수정 없으므로 과교정 지표 없음)

- [ ] 라우팅 정밀도: P3가 위험 표시한 것 중 실제 문제 비율 ≥50%인가?
      (50% 미만 = 아침 보고가 노이즈化 → 문구 아닌 RAG 커버리지 점검)
- [ ] 라우팅 재현율: 심은 오류 중 P3가 잡은 비율 ≥70%인가?
- [ ] 리콜↔프리시전 상충 시 pareto-optimization-gate 로드

## 금지 사항 (게이트 무결성)

- 실험 중 문항·채점 기준 수정 금지 (Goodhart 방어 — 수정 필요하면 실험 폐기 후 재시작)
- 프로브 지적 건수를 KPI로 삼는 것 금지 (프로브 게이밍)
- 통과 전 "효과 있다" 보고 금지 — "실측 대기 중"이 정직한 상태 표기
